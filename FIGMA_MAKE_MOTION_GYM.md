# GetYourMentor - Prompt motion et direction visuelle v2

## Objectif

Ce prompt sert a generer une maquette `Figma Make` plus ambitieuse visuellement, avec :

- une inspiration visuelle premium proche de la capture d'ecran partagee
- une adaptation claire au style "Planity-like"
- quelques animations de navigation plus marquantes

## Important

La capture d'ecran doit etre utilisee comme **reference de style**, pas comme modele a recopier a l'identique.

Le produit final doit rester :

- plus clair
- plus rassurant
- plus lisible
- plus orientee reservation

## Prompt a coller apres le prompt principal

```text
Use the attached screenshot only as a style inspiration, not as a 1:1 rebuild.

I want a more premium visual direction for GetYourMentor:
- keep the product logic and UX very Planity-like
- keep the interface clearer and more reassuring than the attached fitness concept
- keep the terracotta / orange energy from the reference
- keep a layered, cinematic, premium composition for hero areas and transitions

Visual adaptation rules:
- do not switch the whole product to a dark dashboard style
- keep the main product screens mostly light, warm, and elegant
- use dark charcoal only in selected hero or transition backgrounds
- preserve the warm cream surfaces and terracotta CTA system
- keep the UI conversion-oriented and easy to scan

I want subtle motion with a premium feel:
- add a light 3D carousel-like transition between major screens
- make the screens feel as if they rotate around a central vertical axis in a circular path
- keep the effect elegant and short, never flashy
- use perspective, depth, and slight scale changes
- preserve readability during motion
- add subtle staggered reveals for cards and coach results
- add gentle hover and press states on buttons and cards

Motion rules:
- transitions should feel smooth and premium
- duration should feel around 450ms to 700ms
- use easing that feels natural and not playful
- the 3D effect should be subtle enough to still feel realistic for a premium booking product
- use motion mostly between page states, not everywhere

For the hero section:
- create a stronger visual composition
- include one or more tilted mobile device mockups or layered app panels
- make the hero feel premium and dynamic without becoming a generic fitness app
- keep the booking/request value proposition obvious in the hero

For the rest of the product:
- keep coach cards, filters, booking steps, and dashboard highly readable
- maintain strict alignment, centered composition, and consistent spacing

Do not change the core flow:
- search
- results
- coach profile
- choose session
- choose preferred timeslots
- login/signup
- review request
- send request
- coach approves later
- payment only after approval

If true 3D page orbit is too heavy, simulate it with layered perspective transitions and smart depth changes while keeping the app stable and responsive.
```

## Resultat attendu

Le rendu doit ressembler a :

- un produit de reservation premium
- une plateforme sportive credible
- une experience plus vivante que Planity
- mais plus claire et plus rassurante qu'une app fitness dark classique
