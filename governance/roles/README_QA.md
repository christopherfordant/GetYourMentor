# README QA

## Mission

Verifier que le produit livre respecte le fil rouge, les parcours critiques et la non-regression visuelle / metier.

Le role QA controle la conformite au document maitre sur les parcours MVP.

## Responsabilites

- controle des parcours principaux
- controle des regressions Next vs prototype
- controle de coherence documentaire visible
- remontes des ecarts critiques

## Priorites

1. home
2. recherche
3. selection coach
4. fiche coach
5. reservation
6. paiement

## Criteres de qualite

- parcours testables de bout en bout
- ecarts classes par severite
- verifications visuelles sur desktop et mobile

## Dependances

- CTO pour l'arbitrage des risques
- Design pour les ecarts visuels
- Product pour les comportements attendus

## Alertes

- texte casse
- liens metier casses
- pages Next incoherentes avec la reference
- tunnel de reservation rompu

## Checklist fil rouge

- le flux trouver > reserver > payer est-il intact
- les pages critiques restent-elles lisibles et credibles
