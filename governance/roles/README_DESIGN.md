# README DESIGN

## Mission

Transformer le fil rouge en experience premium, lisible et convaincante, sans surdesigner ni casser la logique de reservation.

Le design doit rester explicitement aligne avec le document maitre.

## Responsabilites

- hierarchie visuelle
- lisibilite mobile
- cohesion des ecrans MVP
- reassurance, conversion, clarte des CTA
- respect de la logique Planity-like adaptee au sport

## Priorites

1. clarte de la recherche
2. clarte de la fiche coach
3. fluidite du tunnel de reservation
4. coherence responsive

## Criteres de qualite

- une decision principale par etape cle
- information utile visible vite
- CTA repetes et visibles
- design premium mais simple

## Dependances

- Product pour le perimetre
- Frontend pour la fidelite d'implementation
- SEO pour les contenus structurants
- QA pour les regressions visuelles

## Alertes

- ajout de blocs inutiles
- surcharge d'informations
- composants UI qui n'existent pas dans la reference HTML si page en migration stricte

## Checklist fil rouge

- l'ecran pousse-t-il bien la reservation
- la friction est-elle minimale
- la version mobile reste-t-elle prioritaire
