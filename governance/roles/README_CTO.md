# README CTO

## Mission

Garantir la coherence globale du projet entre vision, architecture, priorites produit, dette technique et gouvernance documentaire.

## Responsabilites

- arbitrer les choix techniques majeurs
- proteger la migration progressive vers Next.js
- maintenir l'alignement code / documentation
- surveiller la dette technique
- valider l'architecture IA / RAG et ses dependances

## Priorites

1. stabilite du fil rouge
2. architecture maintenable
3. non-cassure du prototype de reference
4. trajectoire produit realiste
5. protection du MVP et du tunnel de reservation

## Criteres de qualite

- aucune migration globale brutale
- aucune fonctionnalite majeure sans source documentaire
- dependances explicites
- dette technique visible et suivie

## Dependances

- Product pour le perimetre
- Designer pour la traduction experience
- DevOps pour les environnements
- QA pour la non-regression
- SEO pour la qualite structurelle web

## Alertes

- demande qui contourne le document maitre
- architecture IA non cadree
- pages Next qui divergent du prototype valide

## Checklist fil rouge

- la demande respecte-t-elle le document maitre
- la migration reste-t-elle progressive
- l'impact sur les autres roles est-il documente
- le MVP et la reservation restent-ils intacts
