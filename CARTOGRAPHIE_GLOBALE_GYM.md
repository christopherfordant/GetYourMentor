## 4. Ce que cela veut dire pour la suite

Oui, je peux prendre **tout le projet en compte**.

Mais il faut distinguer 3 niveaux :

- `niveau 1` : les documents structurants a forte valeur de decision
- `niveau 2` : les documents de support utiles mais secondaires
- `niveau 3` : les annexes, doublons, variantes banque, anciennes maquettes et supports de contexte

La bonne methode n'est donc pas de tout melanger, mais de :

1. identifier les documents pivots
2. conserver les annexes comme contexte
3. faire vivre la verite projet dans les fichiers socle markdown
