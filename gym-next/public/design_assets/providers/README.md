# Icône Google

`google-g.png` provient de https://developers.google.com/static/identity/images/g-logo.png, lié depuis les consignes officielles https://developers.google.com/identity/branding-guidelines (consultées le 15 octobre 2026).

Asset de marque téléchargé sans modification, proportions conservées. Aucune revendication de licence générique sur la marque Google. Affichage local sur fond blanc ; aucun SDK ou appel Google à l’exécution. Le bouton associé est explicitement indisponible et désactivé : OAuth n’est pas configuré dans cette application.
