## Comment l'ouvrir

Sous Windows :

1. aller dans le dossier `GetYourMentor`
2. double-cliquer sur `PREVIEW_MAQUETTE_GYM.html`

Ou en terminal PowerShell :

```powershell
Start-Process .\PREVIEW_MAQUETTE_GYM.html
```
